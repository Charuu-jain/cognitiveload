# CogniLoad 🧠
### Rule-Based Cognitive Load Estimation System for Academic Reading Material

A web-based tool that analyzes academic PDF/DOCX documents and helps instructors 
identify complex content using a Cognitive Load Index (CLI) score.

## Features
- 📄 PDF & DOCX document upload
- 🌡️ Paragraph-level CLI scoring with color-coded heatmap
- 📝 Extractive document summarization
- ✍️ Grammar error detection
- 📚 Related study material suggestions
- 🧠 Auto-generated quiz from document content
- 🃏 Flashcards for key concepts
- 🔐 User authentication with email OTP verification

## Tech Stack
Java | Spring Boot | Thymeleaf | MySQL | Apache POI | Apache PDFBox | OpenNLP
